# BITS Sem-2 Interactive Study App
Live: https://antonyalexk.github.io/bits-study-app/
Quiz, flashcards, numerical practice, slow-paced note listening, mock exams, and progress tracking for ACI, Computer Vision, Deep RL, and NLP. Open index.html.

Listen mode uses the browser's installed English voices. Speech stays on the device and requires no API key.
